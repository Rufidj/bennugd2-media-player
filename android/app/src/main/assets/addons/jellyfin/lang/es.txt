# Traducción al español del addon de Jellyfin: "texto original => traducción" (las partes {entre llaves} se dejan igual)
Server address (like http://192.168.1.50:8096) => Dirección del servidor (por ejemplo http://192.168.1.50:8096)
User name => Nombre de usuario
Access token (filled by Sign in) => Token de acceso (lo rellena Iniciar sesión)
User id (filled by Sign in) => Id de usuario (lo rellena Iniciar sesión)
Device id (made automatically) => Id del dispositivo (se crea solo)
Password (leave empty if the user has none) => Contraseña (déjala vacía si el usuario no tiene)
Signed in! Press circle and open Jellyfin again => ¡Sesión iniciada! Pulsa círculo y abre Jellyfin otra vez
Signed in to the demo server! Press circle and open Jellyfin again => ¡Sesión iniciada en el servidor de demostración! Pulsa círculo y abre Jellyfin otra vez
Signed out. Press circle and open Jellyfin again => Sesión cerrada. Pulsa círculo y abre Jellyfin otra vez
Sign in to a Jellyfin server => Iniciar sesión en un servidor Jellyfin
Type the address of the server, your user and your password. Only an access token is stored, in the addon settings. => Escribe la dirección del servidor, tu usuario y tu contraseña. Solo se guarda un token de acceso, en los ajustes del addon.
Try the public demo server => Probar el servidor de demostración público
The official Jellyfin demo server, with free sample movies, shows and music. No account needed. => El servidor de demostración oficial de Jellyfin, con películas, series y música de muestra gratuitas. No hace falta cuenta.
Library => Biblioteca
Continue watching => Seguir viendo
What you were watching => Lo que estabas viendo
Search... => Buscar...
Sign out => Cerrar sesión
Search the server => Buscar en el servidor
Nothing found for '{words}'. => No se ha encontrado nada para '{words}'.
